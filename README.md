# Repositório de Empreendimentos

Apresentações, books e implantações de empreendimentos de Jundiaí e região, organizados por empreendimento e incorporadora.

**Site:** https://augusto-franco2610.github.io/repositorio-empreendimentos/

- `index.html` — página com busca, filtro por incorporadora e botões para abrir, baixar e enviar pelo WhatsApp
- `acervo.json` — lista de empreendimentos e materiais (o que a página lê)
- `pdf/` — materiais em PDF, comprimidos para abrir rápido no celular
- `capas/` — capa de cada empreendimento

Ficha completa e simulador de financiamento dos empreendimentos da coordenação: [Portal de Empreendimentos](https://augusto-franco2610.github.io/portal-empreendimentos/).
